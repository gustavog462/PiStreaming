## Argumentos ffmpeg (observados)

```
-v error -y -re -probesize 1M -analyzeduration 0 -rw_timeout 15000000
-i <raw_url>
-map 0:v:0 -map 0:a:0?
-c:v copy -c:a aac -b:a 192k -ac 2
-flush_packets 1
-movflags frag_keyframe+empty_moov+default_base_moof
-f mp4 <cache>/<hash>/playback.mp4

# recode de vídeo:
-c:v libx264 -preset veryfast -crf <n> -maxrate <n> -bufsize <n>

# subtítulos a VTT:
ffmpeg -v error -y -i <input> -map 0:s:0 -f webvtt -
```
